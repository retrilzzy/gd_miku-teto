# 🌟 MIKU & TETO BORDER

Adds a cute Hatsune Miku and Kasane Teto border to all Geometry Dash levels.

> **Inject pure VOCALOID and UTAU hype straight into your Geometry Dash!**

## Manual Installation (GitHub Releases)

1. Make sure [Geode](https://geode-sdk.org/) is installed for Geometry Dash.
2. Download the latest `.geode` file from [GitHub Releases](https://github.com/retrilzzy/gd_miku-teto/releases/latest).
3. Open Geometry Dash and click the **Geode** button on the main menu.
4. Click the **Settings** (gear) button in the bottom-left corner.
5. Click **Install From File** and select the downloaded `.geode` file.
6. Restart Geometry Dash.

## Ручная установка (GitHub Releases)

1. Убедитесь, что для Geometry Dash установлен [Geode](https://geode-sdk.org/).
2. Скачайте последний `.geode` файл со страницы [GitHub Releases](https://github.com/retrilzzy/gd_miku-teto/releases/latest).
3. Откройте Geometry Dash и нажмите кнопку **Geode** в главном меню.
4. Нажмите кнопку **настроек** (шестерёнка) в левом нижнем углу.
5. Нажмите **Install From File** и выберите скачанный `.geode` файл.
6. Перезапустите Geometry Dash.
